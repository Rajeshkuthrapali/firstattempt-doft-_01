## ADDED Requirements

### Requirement: Delete stale .txt output files
The system SHALL delete all stale `.txt` output files from the project root that were produced by past development tool runs and have no ongoing purpose.

In scope:
- `tsc_errors.txt`
- `tsc-errors.txt`
- `ts_errors.txt`
- `tsc_final.txt`
- `test-pure.txt`
- `test-output.txt`
- `full-test.txt`
- `cart-test.txt`
- `home-test.txt`
- `layout-test.txt`
- `nav-err.txt`
- `eslint_errors.txt`
- `lhci_output.txt`

#### Scenario: Delete stale txt output files
- **WHEN** the cleanup script or manual deletion is performed
- **THEN** all 13 files above SHALL be removed from the project root
- **THEN** no existing functionality SHALL be affected by their removal

### Requirement: Delete stale .json result files
The system SHALL delete all stale `.json` result files from the project root that were produced by past test/ESLint runs and have no ongoing purpose.

In scope:
- `test-result.json`
- `test-results.json`
- `final-results.json`
- `eslint_errors.json`
- `eslint_final.json`
- `eslint_final3.json`
- `e2e-report.json`

#### Scenario: Delete stale json result files
- **WHEN** the cleanup is performed
- **THEN** all 7 files above SHALL be removed from the project root

### Requirement: Delete generated and cache directories
The system SHALL delete generated output directories that are recreatable via standard tool commands.

In scope:
- `playwright-report/` — regenerated by `npx playwright test`
- `test-results/` — regenerated by `npx playwright test`
- `.lighthouseci/` — regenerated by `lhci autorun`

#### Scenario: Delete generated directories
- **WHEN** the cleanup is performed
- **THEN** `playwright-report/`, `test-results/`, and `.lighthouseci/` directories SHALL be deleted

### Requirement: Delete broken and orphaned files
The system SHALL delete files at project root that are broken (reference non-existent code) or orphaned (config for unused tools).

In scope:
- `check-db.ts` — references `prisma.customer` (model doesn't exist) and root `@prisma/client` (Prisma is in `server/`)
- `.hintrc` — webhint configuration for a tool not installed or used anywhere in the project

#### Scenario: Delete broken check-db script
- **WHEN** the cleanup is performed
- **THEN** `check-db.ts` SHALL be deleted from the project root

#### Scenario: Delete orphaned hintrc config
- **WHEN** the cleanup is performed
- **THEN** `.hintrc` SHALL be deleted from the project root

### Requirement: Delete stale infrastructure scripts
The system SHALL delete speculative infrastructure scripts that reference non-existent deployment environments.

In scope (from `scripts/`):
- `backup-now.sh`
- `drill-db-failover.sh`
- `pitr-restore-test.sh`
- `smoke-prod.sh`
- `run-k6-mock.ps1`

The following scripts SHALL be preserved (they are used by CI or actively useful):
- `load-test.js`, `storefront-load-test.js`, `checkout-load-test.js`, `concurrent-checkout-load-test.js` — k6 load tests used by CI
- `webhook-harness.ts` — utility for testing webhook endpoints

#### Scenario: Delete stale infrastructure scripts
- **WHEN** the cleanup is performed
- **THEN** the 5 infrastructure scripts listed above SHALL be deleted from `scripts/`
- **THEN** the 5 preserved scripts SHALL remain untouched
